# 검증 페이지는 테스트 영역의 HTML을 안전하게 읽고, 실제 영역을 다시 읽어 비교합니다

검증 페이지의 테스트 영역은 HTML 원문을 쓰는 `textarea`입니다. Patch를 누르면 그 HTML을 `<template>`로 읽고, 실제 영역을 다시 읽은 `View`와 비교해 바뀐 곳만 반영합니다. 이력에는 저장된 현재 `View`와 다를 때만 쌓습니다.

## Patch

1. **읽기:** 테스트 영역의 HTML을 `<template>`로 읽습니다. `<template>` 안에서는 스크립트가 실행되지 않고 이미지도 불러오지 않습니다.
2. **지우기:** 코드를 실행하거나 페이지를 옮길 수 있는 것을 지웁니다. `script`, `iframe`, `object`, `embed`, `meta`, `base`, `link` 요소와 `on`으로 시작하는 속성, `srcdoc`, 값에 `javascript:`가 든 속성입니다. 브라우저는 URL 안의 공백과 제어 문자를 무시하므로, 그것을 뺀 값으로 확인합니다.
3. **맞추기:** 주석을 지우고 붙은 글자 노드를 합칩니다. 그래야 저장한 `View`를 HTML로 만들고 다시 읽었을 때 같은 `View`가 됩니다. 실제 영역도 처음 읽기 전에 같은 처리를 합니다.
4. **최상위 노드:** 공백 글자를 빼고 요소가 정확히 하나여야 합니다. 아니면 반영하지 않고 "최상위 노드가 하나 필요합니다"를 보여 줍니다. 이력과 앞쪽 기록도 그대로 둡니다.
5. **비교와 반영:** 실제 영역을 `createVNodeFromDom`으로 다시 읽어 새 `View`와 비교하고, 그 Patch를 적용합니다. 그래서 Patch 뒤에는 실제 영역이 언제나 테스트 영역과 같습니다.
6. **저장:** 새 `View`가 `StateHistory`의 현재 `View`와 다를 때만 `push`합니다. 바뀐 것이 없으면 DOM도 이력도 그대로입니다(뒤로 간 자리에서도 앞쪽 기록이 남습니다). 실제 영역의 입력칸에 직접 친 값만 다를 때도 이력은 쌓이지 않습니다.

## 뒤로가기와 앞으로가기

`StateHistory`에서 꺼낸 `View`를 실제 영역에 Patch로 반영하고, 테스트 영역은 그 `View`의 HTML로 바꿉니다. 저장하지 않은 테스트 영역의 편집은 버립니다. 경고창이나 자동 저장 같은 새 동작을 만들지 않기 위해서입니다.

## 오류

`applyPatchesToDom`은 오류가 나도 앞서 적용한 변경을 되돌리지 않습니다(ADR 0006). 그래서 페이지가 수습합니다. 적용 중에 오류가 나면 지금 보여야 할 `View`로 실제 영역을 새로 그리고, 오류를 안내에 보여 줍니다. Patch에서 난 오류면 이력에 쌓지 않습니다.

## 테스트

기능 테스트는 jsdom에서 `index.html`과 실제 입구 함수 `startVerificationPage`로 페이지를 만들고, 버튼을 눌러 확인합니다. 실제 브라우저의 키 입력과 한글 조합은 사람이 직접 확인합니다. 브라우저 러너는 새 의존성이므로 들이지 않습니다.

## 고려한 대안

- **`contenteditable` 테스트 영역:** 화면을 바로 고칠 수 있지만, 브라우저마다 만드는 HTML이 다르고 최상위 노드를 하나로 지키기 어렵습니다. 팀 테스트 시트도 "테스트 영역의 HTML"을 전제합니다.
- **Patch를 이력의 현재 `View`와 비교:** 실제 영역의 입력칸에 직접 친 값이 Patch 뒤에도 남아, 두 영역이 다르게 보입니다. 뒤로가기는 실제 영역을 읽으므로 기준도 둘로 갈립니다.
- **`script`와 `on` 속성만 지우기:** 팀 테스트 시트 88행의 요구는 그것뿐이지만, `javascript:` URL과 `iframe`, `meta` 같은 다른 실행 경로가 남습니다.

## 결과

- `<pre>`와 `<textarea>`는 HTML 파서가 여는 태그 바로 뒤의 줄바꿈을 버립니다. 그 줄바꿈으로 시작하는 글자는 HTML을 거치면 달라지므로, 뒤로 간 자리에서 바뀐 것 없는 Patch가 이력을 쌓을 수 있습니다. 드문 입력이므로 다루지 않습니다.
- 바뀐 곳 강조(팀 테스트 시트 92행, 선택)는 만들지 않습니다.
