# `Patch`는 `TEXT`, `REPLACE`, `PROPS`, `INSERT`, `REMOVE` 다섯 종류이고, 끼워 넣는 일은 `CREATE`가 아니라 `INSERT`라 부릅니다

> [!CAUTION]
> 팀 테스트 시트의 `CREATE`를 그대로 쓰면, `CONVENTION.md` 동사 표에서 `create`가 뜻하는 "새로 만들어 돌려줍니다"와 DOM에 끼워 넣는 일이 섞입니다.

결정: (테스트: P1, P3, P4, P5, P6, P7, P8, P9, P29, D5, D10, D16, D24, D25)
