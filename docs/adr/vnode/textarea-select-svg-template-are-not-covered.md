# `textarea`, `select`, `checkbox`, `radio`, `file`, SVG, `<template>`는 전용 변환 규칙을 두지 않습니다

> [!CAUTION]
> `checkbox`와 `radio`의 상태는 `.checked`에 있고, `checkbox`와 `radio`의 상태는 `.checked`에 있고, `textarea`는 자식 글자가 처음 값으로 남고, `select`는 `selected` 속성이 처음 고른 항목으로 남고, SVG는 HTML 이름공간으로 만들면 `viewBox`의 대소문자가 사라지고, `<template>`은 내용이 `childNodes`가 아니라 `content`에 있습니다.
