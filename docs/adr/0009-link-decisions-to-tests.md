# ADR의 결정과 테스트를 ID로 잇고, 연결은 스크립트가, 뜻은 새 세션 리뷰가 확인합니다

결정은 ADR에 적고, 테스트는 그 결정을 실행해서 지킵니다. 같은 결정이 두 곳에 있으므로 한쪽만 바뀌면 서로 어긋납니다. 그래서 ADR 항목 끝에 `(테스트: T9, T26)`처럼 그 결정을 지키는 테스트 ID를 적고, 어긋남은 성격이 다른 세 층에서 나눠 잡습니다. 한 층이 놓친 어긋남을 다른 층이 잡도록, 층마다 다른 방식을 씁니다.

## 층

- **쓰는 규칙:** `CONVENTION.md`의 "결정과 테스트 잇기"입니다. 에이전트는 `AGENTS.md`를 통해 매 세션 읽습니다. 지키는지는 쓰는 쪽의 판단에 달려 있습니다.
- **스크립트:** `scripts/check-decision-links.mjs`이며, `npm run check`가 부르므로 CI에서도 돕니다. ID가 끊긴 어긋남을 잡습니다. ADR이 테스트에 없는 ID를 인용하거나, 인용의 형식이 조금이라도 다르거나(`(테스트:T9)`, 전각 괄호), 두 테스트가 같은 ID를 쓰면 실패합니다. 다음은 목록으로만 보여 줍니다: 아직 `it.todo`인 테스트를 인용한 곳, 대체된 ADR만 인용하는 테스트, ID로 시작하지 않는 테스트, `origin/main` 이후 새로 생겼는데 인용되지 않은 테스트.
- **새 세션 리뷰:** 코드를 작성하지 않은 새 세션이 PR 전에 diff를 검토하고, 결과를 PR 템플릿의 `새 세션 리뷰`에 적습니다. ID는 이어져 있는데 뜻이 어긋난 경우를 잡습니다. 예를 들어 ADR은 "빈 글자 노드를 버리지 않는다"고 하는데 바뀐 테스트는 버린다고 기대하는 경우입니다. 스크립트가 보여 준 새 테스트 목록에서 결정을 지키는 테스트를 골라 인용을 더하는 일도 이 층이 맡습니다.

어떤 기록에도 드러나지 않는 어긋남은 위 세 층이 잡지 못합니다. 팀원이 결정을 말로 설명하다 막히는 곳에서 드러납니다.

## 고려한 대안

- **ADR 본문 전체에서 ID처럼 생긴 글자 찾기:** 인용 형식을 정하지 않아도 되지만, ADR 0005의 `M3`처럼 ID가 아닌 글자를 잘못 잡습니다. 위에 적은 인용 형식의 괄호 안만 읽습니다.
- **인용되지 않은 테스트를 모두 실패로 처리:** 대부분의 테스트는 "요소를 만든다"처럼 뻔한 동작을 지키므로 인용할 결정이 없습니다. 실패 대신 새로 생긴 것만 목록으로 보여 줍니다.
- **에이전트 스킬로 검사:** 스킬은 그 스킬을 가진 에이전트가 기억해서 불러야 돕니다. 팀원의 에이전트도 읽는 `CONVENTION.md`와, 누구의 컴퓨터에서나 같이 도는 스크립트로 나눴습니다.
- **커밋 훅:** `.git/hooks`는 저장소가 추적하지 않아 팀원마다 설치해야 하고, 작업 중간 커밋까지 막습니다. 검사는 PR 단위로 충분합니다.
- **GitHub Action으로 리뷰 자동 실행:** 리뷰를 잊을 수 없게 되지만, API 키와 비용과 외부 서비스가 필요합니다. 리뷰가 자주 빠지면 다시 검토합니다.

## 결과

- PR의 CI는 `origin/main`을 받아 오지 않으므로, 새 테스트 목록은 CI에서 건너뛰고 로컬의 `npm run check`에서 보입니다. 이 목록을 쓰는 새 세션 리뷰는 로컬에서 돌기 때문입니다.
- 스크립트는 `src/`의 `*.test.ts`에서 `it(`, `test(`, `it.todo(`처럼 부르는 테스트의 이름이 ID로 시작하면 그 ID를 읽습니다. `it.each(...)(...)`처럼 이름을 나중에 넘기는 형태는 읽지 못합니다. ADR의 인라인 코드 안에 적은 인용은 형식을 설명하는 예시로 보고 읽지 않습니다.
- `describe.skip`으로 건너뛰는 테스트도 인용할 수 있습니다. 공통 테스트는 구현 전에 건너뛰는 규칙이 있기 때문입니다. 이 PR을 만든 시점의 `main`에서는 ADR 0005가 인용한 테스트가 모두 건너뛰는 중입니다.
- 이 PR에서 ADR 0005에 인용을 처음 적었습니다. 그 과정에서 "값이 빈 속성도 버리지 않는다"는 결정이 테스트(T9, T26)에만 있고 ADR에는 없어서 항목을 더했습니다. 새 세션 리뷰에서 인용 넷이 문장과 뜻이 맞지 않는다는 지적을 받아 고쳤습니다. 그중 하나는 "다루지 않는다"는 문장에 반대 동작을 지키는 P38을 인용한 것이었습니다. ADR 0006~0008의 인용은 아직 없습니다.
